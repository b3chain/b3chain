# Security Policy

## Supported Versions

B3Chain Core is currently in pre-launch development. All versions on the
`b3chain-main` branch receive security updates.

## Reporting a Vulnerability

To report security issues, send an email to **security@b3chain.org** (not for support).

Please do not disclose vulnerabilities publicly until a fix has been released
and coordinated disclosure has been agreed upon.

We aim to:
- Acknowledge reports within 24 hours
- Provide an initial assessment within 72 hours
- Coordinate public disclosure after the fix is deployed

## Upstream Security

B3Chain is based on Bitcoin Core. Security fixes from upstream Bitcoin Core
are cherry-picked promptly. For Bitcoin Core security issues, see
https://bitcoincore.org/en/lifecycle/#schedule
