# B3Chain Phase 11: Security Audit Checklist

This document is the master checklist for the B3Chain self-audit. Each item is
backed by an automated test script and a public detail page on
[b3chain.org/testing](https://b3chain.org/testing.html).

**Status legend:**
- `[x]` PASSED — script exited 0 and all assertions held
- `[!]` FAILED — script reported a problem; see notes
- `[ ]` PENDING — script not yet run
- `[-]` N/A — item documented but not testable in current state

**Scope:** This is a self-audit, not an external audit. It covers the
B3Chain-specific code and the integration of BLAKE3 into Bitcoin Core. It does
**not** re-audit the underlying Bitcoin Core 30.2.0 code.

## How to run the full audit

```bash
cd b3chain
bash contrib/testing/audit/run-all.sh
```

This builds `b3chaind` (if not already built), runs all audit scripts in order,
and prints a summary table. Exit code is 0 only if every audit passes.

Individual audits can be run standalone:

```bash
python3 contrib/testing/audit/audit-supply-cap.py
python3 contrib/testing/audit/audit-pow-isolation.py
python3 contrib/testing/audit/audit-network-isolation.py
python3 contrib/testing/audit/audit-address-rejection.py
python3 contrib/testing/audit/audit-simd-blake3.py
bash   contrib/testing/audit/audit-rebranding.sh
python3 contrib/testing/audit/audit-hd-coin-type.py
python3 contrib/testing/audit/audit-51-attack-sim.py
bash   contrib/testing/audit/audit-internal-miner.sh
```

## Reporting

Audit failures are tracked as GitHub issues with the `audit-failure` label.
Security-relevant findings should be reported privately to
**security@b3chain.org** before public disclosure.

## Findings and remediation (Phase 11 first run)

The first end-to-end run of the audit caught the following genuine
regressions that were left over from the rebranding pass and have been
fixed in this commit set:

| Source | Finding | Resolution |
|--------|---------|------------|
| `src/qt/addressbookpage.cpp` | "These are your **Bitcoin** addresses..." appeared in two `tr()` strings | Both replaced with "B3Chain" |
| `src/qt/intro.cpp`           | First-run dialog said "the **Bitcoin** block chain" | Replaced with "B3Chain" |
| `src/qt/guiutil.cpp`         | Address-field placeholder said "Enter a **Bitcoin** address (e.g. %1)" | Replaced with "B3Chain" |
| `src/qt/sendcoinsdialog.cpp` | Three PSBT tooltip / confirmation strings said "Partially Signed **Bitcoin** Transaction" | All three replaced with "B3Chain" |
| `src/rpc/rawtransaction_util.cpp` | Error message "Invalid **Bitcoin** address" raised by `createrawtransaction` | Replaced with "B3Chain" |
| `doc/Doxyfile.in` | Generated doxygen project name was "Bitcoin Core" | Changed to "B3Chain Core" |
| `contrib/asmap/README.md`, `contrib/devtools/README.md`, `contrib/init/README.md`, `contrib/linearize/README.md`, `contrib/message-capture/`, `contrib/qos/README.md`, `contrib/README.md`, `contrib/signet/README.md`, `contrib/tracing/README.md` | References to `bitcoind` / `bitcoin-cli` / `bitcoin-qt` / `bitcoin.conf` in command examples | Bulk-renamed to `b3chain*` equivalents |
| `doc/b3chain-bip44.md` (introduced this commit), `doc/developer-notes.md`, `doc/files.md`, `doc/release-notes.md`, `doc/release-process.md`, `src/qt/README.md` | Stray `bitcoind` / `bitcoin-qt` / `bitcoin-tx` references in narrative documentation | Renamed to `b3chain*` equivalents |

References that were intentionally left alone (and are now whitelisted in
`audit-rebranding.sh`):

- Copyright lines and "The Bitcoin Core developers" attribution.
- Lines that contrast old and new names (e.g. `README.md` rename table).
- External URLs (e.g. flathub paths under `org.bitcoincore`).
- The `src/bitcoin-*.cpp` source filenames (we do not rename source files
  to avoid unnecessary churn against upstream merges).
