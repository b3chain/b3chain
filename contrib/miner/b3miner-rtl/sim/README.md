# sim/

Test infrastructure for the b3miner-rtl tree.

## Layout

```
sim/
├── verilator/      Verilator harness (primary -- fast, FOSS, no Vivado licence)
├── xsim/           XSIM fallback (only for tests of Xilinx-IP primitives)
├── tb/             SystemVerilog testbenches (shared by both flavours)
└── vectors/        Plain-hex test vectors (generated by ../ref/gen_vectors.py)
```

## Running

From the tree root (`b3miner-rtl/`):

```
make vectors                # regenerate sim/vectors/*.hex from the Python ref
make sim                    # run every TB via Verilator
make sim-one TB=tb_b3miner_top   # run one TB
```

Each TB is a SystemVerilog top with no ports. `verilator/Makefile`
builds one simulation binary per TB, driven by the generic
`sim_main.cpp` (it just clocks the simulation until `$finish`).

## TB inventory

| TB | Covers | Vector file |
|---|---|---|
| `tb_blake3_compress.sv` | `rtl/blake3_compress.sv` | `blake3_compress.hex` |
| `tb_blake3_xof.sv` | `rtl/blake3_xof.sv` | `blake3_xof.hex` |
| `tb_spi_slave.sv` | `rtl/spi_slave.sv` | `regfile_trace.hex` |
| `tb_regfile.sv` | `rtl/regfile.sv` + spi_slave | `regfile_trace.hex` |
| `tb_scratchpad_mem.sv` | `rtl/scratchpad_mem.sv` | (self-checking) |
| `tb_scratch_init.sv` | `rtl/scratch_init.sv` | `scratch_init.hex` |
| `tb_mixing_core.sv` | `rtl/mixing_core.sv` | `mixing_one_iter.hex` |
| `tb_b3miner_top.sv` | full chip end-to-end | `full_hash.hex` + `regfile_trace.hex` |

## Vector format

Each `*.hex` file has one record per non-comment line:

```
# comment lines start with '#'
<label>: <hex-bytes-1> <hex-bytes-2> ...
```

The TBs use a small `vector_reader.svh` helper that `$fopen`s the
file, skips comments, and returns one record at a time as raw bytes.

## XSIM fallback

Some Xilinx primitives (MMCME4_ADV, XADC) don't simulate cleanly in
Verilator. For tests that need them, use:

```
cd sim/xsim
vivado -mode batch -source run_xsim.tcl -tclargs tb_b3miner_top
```
